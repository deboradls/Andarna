# 🐉 Andarna

> **Sua jornada entre páginas.**

O **Andarna** é uma plataforma web voltada para leitores, criada para facilitar a **organização, acompanhamento e interação com leituras**.

A proposta é reunir em um único espaço recursos para organizar livros, acompanhar o progresso de leitura, registrar experiências e compartilhar a jornada literária com outros leitores.

## ✨ Sobre o projeto

O Andarna surgiu da ideia de criar uma plataforma que fosse além de uma simples biblioteca virtual.

A aplicação busca proporcionar ao leitor um espaço para:

* Organizar sua biblioteca pessoal;
* Criar e gerenciar estantes;
* Acompanhar o progresso das leituras;
* Registrar anotações e experiências;
* Avaliar livros;
* Interagir com outros leitores.

O projeto está sendo desenvolvido como parte da graduação em **Ciência da Computação** e como projeto acadêmico de desenvolvimento de software.
